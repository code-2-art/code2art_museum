c2a-001 / history / 2010s

HUDOIT 论坛记忆

HUDOIT 是 2010 年代中国活跃的交互媒体论坛之一，也是实验编程社群精神来源之一。这个展品用于收集论坛历史、相关课程、成员记忆和早期作品线索。

c2a-002 / project / 2026

code2art museum 建馆宣言

code2art museum 是一座由社群共同建造、永不竣工的在线数字博物馆，收藏实验编程社群的历史、作品、开源项目与人。

c2a-003 / prompt / 2026

Prompt 即展品

Prompt、Skill、工作流和 AI 协作方法也是实验编程时代的重要创作痕迹，可以被收藏、展示、引用和复用。
